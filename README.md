# Internal Warehouse & Office Supplies Allocation Management

This project is a full-stack MERN application for managing warehouse inventory, internal export allocations, and reporting.

## Structure

- `server/` – Express + MongoDB backend
- `client/` – React + Vite frontend

## Quick start

```bash
npm install
npm run dev
```

## Backend environment

Copy `server/.env.example` to `server/.env` and update values.
